# Budget Tracker — iPhone

Personal budget tracker (fixed / one-off / wants, salary in parts, investment, debt, monthly carry-over, yearly Excel export, RU / EN / UZ).

**Install:** open https://alfatango1.github.io/budget-ios/ in **Safari** → Share → **Add to Home Screen**.

The app works offline. All expenses are stored only on the phone — nothing from the app is uploaded here.
